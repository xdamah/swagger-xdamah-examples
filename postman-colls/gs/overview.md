
## 👋 Introduction

Welcome to the Xdamah getting started Postman workspace. This workspace contains Postman collections that you can quickly use to examine the Xdamah examples. Generally speaking swagger-ui should be enough. But using this postman workspace as an additional interface and also for testing purposes.

## 🛟 Setup steps

Please read how do I get set up in [https://github.com/xdamah/swagger-xdamah-examples](https://github.com/xdamah/swagger-xdamah-examples).

## 🚀 Getting started with this workspace

In this workspace, you'll find many Postman collections that help understand the xdamah examples.

##### BasicExample collections

These collections contain very straighforward general examples.

##### ExtensionExample collections

These collections demonstrate custom validation by extending swagger schema using swagger extensions. They lso demonstrate custom types using one approach.

##### **Polymorphism Examples- A & B**

These collections demonstrate polymorphism.

## **⭐️** Important Notes

-   Each collection will contain requests meant to test/work with one or more Xdamah examples.
    
-   Examples must be setup locally before running the collections.
    
-   Run only one collection at a time. Likewise run only one example at a time.
