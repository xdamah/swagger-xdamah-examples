
## 👋 Introduction

Welcome to the Xdamah More Examples Postman workspace. This workspace contains Postman collections that you can quickly use to examine the Xdamah examples. Generally speaking swagger-ui should be enough. But using this postman workspace as an additional interface and also for testing purposes.

Might be a good idea to first try the Xdamah Getting started Examples Postman workspace before trying this.

## 🛟 Setup steps

Please read how do I get set up in [https://github.com/xdamah/swagger-xdamah-examples](https://github.com/xdamah/swagger-xdamah-examples).

## 🚀 Trying out more examples with this workspace

In this workspace, you'll find many Postman collections that help understand the xdamah examples. Might be a good idea to first try the Xdamah Getting started Examples Postman workspace before trying this.

## **⭐️** Important Notes

-   Each collection will contain requests meant to test/work with one or more Xdamah examples.
    
-   Examples must be setup locally before running the collections.
    
-   Run only one collection at a time. Likewise run only one example at a time.
